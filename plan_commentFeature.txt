Adding a comment feature.

1. Add Comment data from the grids folder to the grid data that comes from the server.
tools.php has functions for getting data from the file system. getDay() reads a grid file and adds it to an object
we should add another function getComments() which iterates through the files in comments folder under that day and adds the comments and file names to a new object attached to the "day" object.
there are test comments at grids/282/288/comments

2. Add Buttons to Grid
The Grid class in util.grid.js will have a button appear over it when the grid is tapped or moused over. 
The comment data should have the "filename" value formatted as: daniel-1792113037-15641
So the first part of the filename "daniel" tells which row it is on, and the comment will be under the "day" object
The constructor of Week in util/week.js will need to be modified. it has the "dayObj" object which has the comment
The constructor of User in util/user.js will need to be modified to pass the comment array in
The constructor of Grid in util/grid.js will need to be modified to take the comment array and determine how the comment bubble would look.
Only grid spaces with actual scores will have the comment button on it
The button will be a speech bubble on it 💬
This button will have a numeric bubble on it if there are any comments on that grid (the bubble shows the quantity of comments)

3. Add a class to add an element to display and submit new comments
the button on the grid will open a div element which displays the grid and then the comments in order according to the comment's file name
The display element will have a text box and a submit button
If the text box is empty the submit button is disabled
When a comment is submitted, the text box is cleared, and an api call is triggered with the data
a new button will appear for a time out to delete the comment. The delete button will work like the grid delete button, it will use $deleteDelay to know when to dissapear.
clicking anywhere off of the display element will close the element
put an × in the upper right corner to close the element

4. Add api end point to submit a comment
The first part of the filename will be generated by the front end
This will go enter through submit.php and use functions similar to tools.php
Please create a new php file "commentTools.php" to handle the comment functions
The comments will be stored in files like the grids, an example is at: grids/282/288/comments
Be sure to send an error if a write fails
the success response will send the file creation time back to the client
so a successful response would look like: {"msgs":[{"to":"clientxx","msg":{"msg":[{"time":1792122472}],"version":9}}]}
However most of this structure comes from outside of the functions we will be making here

5. Add api end point to delete a comment
This will go into submit.php and use functions similar to tools.php
Please add the delete function to "commentTools.php"
like with the grid delete in deleteGrid() of tools.php, the creation time of the file is checked
an error is recorded if the creation time doesn't match or if someone tries to delete the comment after the deletion window has expired.
